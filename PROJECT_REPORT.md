# Comprehensive Project Report: AI Stock Predictor & Financial Advisor

This document serves as a complete, end-to-end project report detailing the theoretical background, technologies used, algorithms implemented, and outputs generated by the AI Stock Predictor & Financial Advisor application.

---

## 1. Core Technologies & UI Stack

The application is built using a modern, decoupled client-server architecture.

### Frontend Technologies (HTML, CSS, JS)
* **React.js**: The core JavaScript library used to build the user interface through reusable, state-driven components (e.g., `StockPrediction.jsx`, `SIPCalculator.jsx`, `FDCalculator.jsx`).
* **Tailwind CSS**: A utility-first CSS framework used for all styling. It replaces traditional vanilla CSS files by applying inline utility classes to HTML elements. This enabled the "glassmorphism" aesthetic (translucent backgrounds with blur), responsive grid layouts, and cohesive color themes (e.g., `#2563EB` for Primary Blue).
* **Framer Motion**: A React animation library used to bring the HTML elements to life. It powers the micro-interactions, such as buttons scaling on hover, chat bubbles sliding in smoothly, and loading spinners.
* **Recharts**: A composable charting library built on React components. It renders complex SVG-based graphs for visualizing the multi-model stock predictions, the SIP compounding curves, and the FD maturity timelines.
* **React Markdown**: Used in the AI Chatbot to parse raw text and render proper HTML typography (bolding, lists, code blocks).

### Backend Technologies
* **FastAPI (Python)**: The high-performance backend framework handling API requests, financial mathematical calculations, and machine learning model coordination.
* **yfinance**: Used to fetch live, historical market data directly from Yahoo Finance for real-time analysis.
* **google-genai**: Powers the intelligent Financial Assistant by communicating with Google's Gemini LLM.

## 2. Machine Learning Algorithms

The core of the stock prediction engine relies on multiple algorithms. Initially, users could select between them, but they are now unified under a robust **Hybrid Model** to prevent user confusion.

### Base Algorithms
1. **Linear Regression**:
   * *Concept*: A fundamental statistical approach that models the relationship between time (days) and stock price by fitting a straight line.
   * *Role*: Serves as a baseline to capture simple, overarching linear trends in the asset's price.
2. **ARIMA (AutoRegressive Integrated Moving Average)**:
   * *Concept*: A classical time-series forecasting model. It combines autoregression (using past values), differencing (to make data stationary), and moving averages (to model noise).
   * *Role*: Excellent at capturing moving averages and cyclical trends, though it can struggle with sudden, non-linear market spikes.
3. **Random Forest Ensemble**:
   * *Concept*: A machine learning method that constructs a multitude of decision trees during training. 
   * *Role*: Captures complex, non-linear market behaviors and prevents overfitting by taking the average prediction of all individual trees.
4. **LSTM (Long Short-Term Memory)**:
   * *Concept*: A highly advanced Recurrent Neural Network (RNN) architecture.
   * *Role*: Designed to remember long-term sequential dependencies in time-series data. It is generally the most suitable standalone algorithm for stock predictions as it learns intricate patterns from historical price movements.

### The Hybrid Model
* *Concept*: Ensemble Averaging.
* *Implementation*: Instead of forcing the user to guess which algorithm is most accurate, the backend runs **all four models simultaneously**. The predicted price for each future day is extracted from Linear Regression, ARIMA, Random Forest, and LSTM. The system then calculates the exact mathematical average of these four values.
* *Output*: A highly stabilized, robust target prediction curve that smooths out the extreme errors or biases of any single algorithm.

## 3. Financial Calculators & Terms

The platform provides mathematically accurate financial tools to help users plan investments.

### Key Financial Terms
* **SIP (Systematic Investment Plan)**: A strategy where an investor invests a fixed amount of money at regular intervals (e.g., monthly) into a mutual fund. 
* **Rupee Cost Averaging**: The primary benefit of an SIP. By investing a fixed amount regularly, you buy more units when prices are low and fewer when prices are high, averaging out the cost per unit over time.
* **FD (Fixed Deposit)**: A low-risk financial instrument provided by banks that guarantees a fixed interest rate until a given maturity date.
* **Compounding Frequency**: How often accumulated interest is added to the principal (e.g., quarterly). The app correctly applies the formula: `A = P * (1 + r/n)^(n*t)`.
* **Bullish vs. Bearish**: A "Bullish" sentiment indicates the algorithm expects the stock price to rise (positive change percentage). A "Bearish" sentiment indicates an expected decline.

## 4. System Outputs & User Experience

When a user interacts with the platform, here is the end-to-end flow of the outputs generated:

1. **Stock Prediction Output**:
   * The user enters a ticker (e.g., `AAPL` or `RELIANCE.NS`).
   * The backend fetches 90+ days of historical data via Yahoo Finance.
   * The system calculates the **Hybrid** prediction for the next 7 days.
   * **Visual Output**: The UI renders a beautiful AreaChart. The x-axis represents time, and the y-axis represents price. A solid baseline indicates the current real-world price, while a dashed/colored area maps the predicted future trajectory.
   * **Analytical Output**: The UI displays a "Target Price" and a "Sentiment" (Bullish/Bearish) based on whether the final day of the hybrid prediction is higher or lower than the current price.

2. **Calculator Outputs (SIP & FD)**:
   * The user inputs their principal, expected return rate, and duration.
   * The backend applies standard compounding formulas. Crucially, mathematical safeguards prevent division-by-zero errors if a 0% return rate is entered.
   * **Visual Output**: The AreaChart draws an exact origin curve starting from Year 0 up to the final duration year. Two distinct areas are mapped: "Amount Invested" (green) and "Total Value" (blue), visually demonstrating the power of compounding interest over time.
   * **Analytical Output**: The UI outputs exactly how much total wealth was generated versus the principal invested, formatting all large numbers with proper Indian currency formatting (₹).

3. **AI Chatbot Outputs**:
   * The user asks a custom financial question.
   * The question is securely routed to the `gemini-2.5-flash` LLM.
   * **Output**: A comprehensive, markdown-formatted response is streamed back to the UI, complete with bullet points and bold headers, providing the user with personalized financial education on demand.
